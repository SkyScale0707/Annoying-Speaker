# agent 基本指令

## agent只读

.gradle\loom-cache\minecraftMaven\net\minecraft下是minecraft 26.3版本的客户端与服务端源码压缩包（对应clientonly与common）。请编写一个skill系列于工作区下.agent\.skill内，分开初步阐述服务端与客户端源码结构；这份skill不是不变的，它应当随着我的一系列提问，将我的问题以及解答概括加入skill中。逐步强化源码的检索能力。这份指令写在.agent\.skill\agent_read.md中，不需要随问题更改。

问答触发关键字：ask

一旦对话中提到**ask**, 便将该轮次回答的问题和产物总结，并归到skill中
